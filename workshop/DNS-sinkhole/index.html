01 Quick start

  1. Copy one or more blocklist URLs below (or grab them all).
  2. Open your sinkhole admin — Pi-hole Adlists or AdGuard Home DNS blocklists.
  3. Paste the URLs, save, then run an update / gravity.
  4. Done — your resolver now refuses the bad domains.

New here? Start with just StevenBlack Unified Hosts and OISD Big — together they cover most ads, trackers and malware without breaking sites.

02 Fine-tuning files

⛒ regex-blacklist.txt Advanced regex rules that block whole patterns of domains, not just single hosts. ✓ whitelist.txt Domains that must never be blocked — even if a blocklist or regex matches them.

Blacklist = block these. Whitelist = always allow these (wins over every blocklist). Use the whitelist to fix false positives.
